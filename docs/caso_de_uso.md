# CASO DE USO

## Sistema

Sistema de Gestão de Produtos para um Mercado.

## Ator

**Funcionário:** utiliza o sistema para controlar os produtos disponíveis no estoque.

## Casos de Uso

### Cadastrar produto

O funcionário informa os dados do produto, como nome, categoria, descrição, preço, quantidade em estoque e data de validade. O sistema valida os dados e cadastra o produto.

### Visualizar produtos

O funcionário acessa a página inicial e visualiza os produtos cadastrados e suas informações.

### Editar produto

O funcionário seleciona um produto cadastrado, altera suas informações e confirma a atualização. O sistema salva as alterações.

### Excluir produto

O funcionário seleciona um produto cadastrado e solicita sua exclusão. O sistema remove o produto do banco de dados.
